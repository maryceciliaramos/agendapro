Sobre o projeto

O Agenda PRO é um sistema desenvolvido para facilitar a organização e o gerenciamento de compromissos e tarefas, permitindo que os usuários tenham mais praticidade no controle de suas atividades diárias.

Funcionalidades
Cadastro de compromissos.
Visualização dos compromissos cadastrados.
Organização de atividades.
Gerenciamento de informações da agenda.
Tecnologias utilizadas
PHP
Laravel
HTML
CSS
JavaScript
MySQL
Como executar o projeto
Clone o repositório:
bash
git clone URL_DO_SEU_REPOSITORIO

Entre na pasta do projeto:
bash
cd agenda-pro

Instale as dependências:
bash
composer install

Copie o arquivo de configuração:
bash
cp .env.example .env

Gere a chave da aplicação:
bash
php artisan key:generate

Configure o banco de dados no arquivo .env.
Execute as migrações:
bash
php artisan migrate

Inicie o servidor:
bash
php artisan serve

Acesse o endereço indicado no terminal pelo navegador.
